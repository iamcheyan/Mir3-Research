> 日期：2026-08-11
> 结论：服务器只使用 EI 版本地图 → 游戏内容边界 = EI 3.0 原版内容体系。
> 玩家从比奇城出发，90 级封顶，终点是神舰 / 赤月恶魔 / 祖玛神殿。
> 与 `map-migration-comparison.md`、`level-equipment-ecosystem.md`、`zircon-vs-ei-updates.md` 配套。

## 2. 为什么地图决定内容边界

怪物刷在哪、NPC 站哪、传送门通向哪、安全区在哪，全部由**地图 + 每张图的 Region 配置**
决定。地图换成 EI 544 张、配置导入 EI（1833 个刷怪点）后，世界 = EI 原版。

```
新手村：比奇城(0) 800×800 / 银杏山谷(02) / 边境城市(01)   → Lv1-10 鸡鹿狼
   ↓
初级洞穴：比奇洞穴 D001-003 / 天然洞穴 D011-012           → Lv13-20
   ↓
中级：沃玛神殿 D021-024 / 祖玛神殿 D501-507               → Lv25-45
   ↓
高级：潘夜神殿 D1101-1105 / 赤月山谷 D1011-10162          → Lv45-75
   ↓

   ↓

特殊：沙巴克城(3) 攻城战 · 矿区 D401-406 挖矿经济
```

**封顶内容**：神舰（Tainted Terror / Netherworld Gate）、赤月恶魔巢穴 D10162
（Red Moon The Fallen）、蚂蚁洞深层（Ant Commander）、祖玛神殿（Zuma King）——
EI 版本最高就到这。

## 4. 玩家玩不到的

Zircon 独有的 199 张地图 + 30+ 西方神话 Boss（苏美尔王 / 奥丁 / 兵马俑 / Doom Claw Lv500）
已从可玩内容移除。怪物定义（309 种）与掉落配置（10382 条）仍在 DB，但无刷怪点 =
游戏内不存在，除非以后恢复。

## 5. 两个推论

1. **Elite 装备（61 件）实际几乎不可达**：全部由 Lv250 Boss 掉落，而玩家 90 级封顶、
   EI 生态 Lv100 怪仅 19 个刷怪点 → Elite 线是断的（纯收藏 / 未来内容）。
2. **199 张 Zircon 独有 .map 是纯冗余文件**：不占游戏逻辑，但想恢复 Zircon 内容时
   它们是现成底料（连同 DB 里的 Boss 定义与掉落）。

## 6. 结论

发展路线 = EI 3.0 原版内容体系（比奇 → 神舰，Lv1-90）。玩家能玩到的就是这 544 张地图
承载的一切，上限是神舰 / 赤月 / 祖玛三个终极区域。方向成立，但 **Elite 装备经济线断裂**——
若要让"90 级毕业"有意义，需补 Boss 入口或调整掉落。
