## 1. 多人任务总则

### 1.1 定位与规则（§3.6 落地）

1. **建议制**：标注"建议 X 人、含 Y 职业"，不硬性卡人；独狼可做但难。
2. **奖励递增**：单人 = 基础奖励，满配队伍 = 满奖励（按队伍构成 CheckDataList/CheckDataValue 判定加成）。
3. **不进入主线依赖**：主线绝不需要先做多人任务（多人任务不产生主线标记，仅产生 M3P_ 计数/货币）。
4. **不放两难/三值**：多人任务纯粹"一起打宝"的快乐——避免队伍争吵（与 10 号 §2/§3 隔离）。
5. **周期性**：Daily/Weekly 节奏；赏金 BOSS 周常轮换、攻城战每周固定时间。
6. **ID 前缀**：`M3P_`（P = Party/Player-group）；07 号总表加"多人任务"分类。
7. **计数**：多人任务完成次数用 `M3P_COUNT_*`（DataValue，仅计数，兑换称号/货币加成）。

### 1.2 能力边界适配

| 设计需求 | 实现方式 |
|---------|---------|
| 组队进入同一 BOSS 房 | VisitRegion（队长触发，队员同图）＋ KillMonster（全队共享计数） |
| 职业分工奖励 | NPCCheck.Class 队伍构成判定（CheckDataValue 队伍计数）→ 奖励加成 |
| 周常轮换 BOSS | QuestType.Weekly ＋ NPCRequirement.DaysOfWeek / 服务端轮换表 |
| 固定时间攻城战 | NPCRequirement.DaysOfWeek＋时段（待服务端扩展：沙巴克开启时间） |
| 结婚（Marriage） | NPCAction.Marriage / Divorce / RemoveWeddingRing ＋ NPCCheck.Marriage / WeddingRing |
| 道侣专属任务 | NPCCheck.Marriage（已婚才可见的 NPC 页面/任务） |

> 定位：★★ 金币+材料。建议 2-3 人，任意职业。周常轮换：每周随机一名 BOSS（沃玛教主/祖玛教主/潘夜牛魔王/骷髅教主），
