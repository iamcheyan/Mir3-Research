## 二、设计缺陷 #4：「三线其一」OR 条件（需拍板）

**问题**：引擎 QuestCanAccept 是 **AND 语义**（PlayerObject.cs:3526-3569，任一 Requirement 不满足即拒）。
设计要的"战士完成 PW4 **或** 法师完成 PM4 **或** 道士完成 PT4"用 3 行 Requirement 会变成 AND（三线全做完才可接）。

**候选方案**：
| 方案 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| A. 拆 3 个任务 ID | M3M_EP1_CONVERGE_WAR / _MAG / _TAO，各挂一个万事通实例 | 零改代码，立即能配 | 任务数量 +2，总表/文档要同步 |
| B. 3 个万事通 NPC 实例 | 比奇/银杏/白日门各一个万事通，各挂一份任务 | 同上，且地图分布自然 | 万事通"多分身"影响剧情统一感 |
| C. 服务端扩展 OR 分组 | 给 QuestRequirement 加 Group 字段（同组 OR，组间 AND）| 最优雅，设计文档不用改 | 要改服务端代码 + 编辑器 |

**建议**：主线汇合这种"三线其一"场景全项目只有 2-3 处（汇合点、终章），**方案 A 拆 ID 最省事**；
若未来大量出现（职业分支任务），再上方案 C 扩展。

## 三、智能体"完全自主创建任务"的资料规划

### 3.1 智能体能自己读什么（无需准备）
| 数据 | 来源 | 说明 |
|------|------|------|
| 怪物/物品/NPC/地图/技能/任务 | `mir2ei` wiki_all.json（System.db 导出）| 英文原始数据，全量 |
| 任务模型/枚举/判定逻辑 | `zircon` 源码 | 已实测可读 |
| 贴图文件 | `mir2ei/img/` + Zircon .Wl/.Zl | 已确认存在 |

### 3.2 需要准备的（智能体读不到或对不上号的）
| 资料 | 内容 | 为什么需要 |
|------|------|-----------|
| **① 语义映射表** | 中文名 ↔ 数据库 ID/英文名：地名↔地图编号、怪物↔MonsterName、物品↔ItemName、NPC↔NPCName、技能↔MagicName | **核心缺口**——wiki_all 是英文，任务文档是中文，智能体对不上号 |
| **② 新资产定义** | 任务道具/技能书/吊坠等新增物品的 ItemInfo 字段 + 贴图来源 | 任务引用不存在的东西会卡死 |
| **③ NPC 图册** | 每个 NPC：形象描述 + 贴图索引 + 位置 + 所属任务类型 | 智能体要"认识"NPC 才能正确使用 |
| **④ 坐标登记** | 剧情地点（望海楼/悬赏板等）的地图编号 + 坐标 | MapRegion 不存在时无法配 VisitRegion |
| **⑤ 任务链完整性** | 前置任务要么先建、要么有占位机制 | HaveCompleted 引用悬空 |
| **⑥ 写入工具** | JSON 配置 → System.db 的导入器 | **自主创建的最后一步**——现在只能读不能写 |

### 3.3 NPC 图册规格（用户提出，重点讨论）

每个 NPC 一页，包含：
```
NPC 中文名 / 英文名（DB ID）
├─ 形象：外貌描述 + 服装特征 + 气质（供美术出图/贴图索引）
├─ 位置：地图编号 + 坐标 + 出没条件（星期几/任务前置）
├─ 贴图：全身像 img/npcs/{id}.png + 头像 img/npcs_face/{id}.png
├─ 身份：商人/任务NPC/剧情NPC/功能NPC
├─ 所属任务：主线 M3M_ / 技能 M3K_ / 副线 M3S_ / 多人 M3P_
├─ 对话风格：口头禅/语气/性格
├─ 好感恩惠：折扣/每日礼/情报（10 号文档联动）
└─ 情感线：与玩家的羁绊/伏笔（08/10 号文档联动）
```

### 3.4 自主创建闭环（目标形态）
```
智能体任务：
1. 读语义映射表 → 中文任务需求 → 数据库 ID
2. 读 NPC 图册 → 选 NPC、位置、贴图
3. 查 06 标记登记 → 新 DataList 防撞名
4. 查 14 能力边界 → 步骤/条件/动作合法
5. 产出 JSON 配置（QuestInfo/NPCInfo/ItemInfo）
6. 写入工具 → System.db → 服务端热载
→ 人工验收：进游戏实测任务
```

### 3.5 建议准备顺序
1. **语义映射表**（最优先，卡住一切）——脚本从 wiki_all 自动生成初版
2. **坐标登记 + 新资产定义**（望海楼等剧情地点、任务道具）
3. **NPC 图册**（按 13 号文档 43 新增 + 19 改造 + 商人分组）
4. **任务链完整性**（M3M_ 系列建库或占位）
5. **写入工具**（SystemDbProbe 扩展 --import 或独立脚本）
