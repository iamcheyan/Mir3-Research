## 2. 战士线（比奇城）——「村卫试炼 · 护村成名」

### 2.1 村卫试炼（M3M_PW1_VILLAGE）

| 字段 | 值 |
|------|-----|
| 任务名 | 村卫试炼 |
| 任务 ID | M3M_PW1_VILLAGE |
| 任务类型 | Story（剧情，一次性） |
| 等级 | 1-7（序章） |
| 接取 NPC | 村长·赵德旺（比奇城村政厅） |
| 交付 NPC | 武教头·铁雄（比奇城武场） |
| 接取条件 | QuestRequirement.Class = Warrior；无等级限制 |
| 前置任务 | 无 |

**任务步骤（QuestTask，并行推进）**

| # | QuestTaskType | 参数 | 说明 |
|---|---------------|------|------|
| 1 | KillMonster | 鸡 ×5（区域：比奇城周边） | 天光惊扰，鸡群乱窜 |
| 2 | KillMonster | 猪 ×3（区域：比奇城周边） | 半兽人袭村前兆 |
| 3 | KillMonster | 半兽人 ×3（区域：比奇城西郊） | 半兽人先锋小队摸进村 |

**奖励（QuestReward）**

| 奖励 | 类型 | 说明 |
|------|------|------|
| 技能书·基本剑术 ×1 | Item | 7 级可学（战士入门） |
| 木剑 ×1 或 轻型盔甲 ×1 | Choice | 二选一 |
| 船长吊坠 ×1 | Item + Bound | 绑定，万事通信物（后续任务钥匙） |
| 金币 ×500 | GiveCurrency | 金币 500 |
| 狩猎币 ×10 | GiveCurrency | 狩猎币 10 |

**对话全文**

- **村长·赵德旺 Say（接取页）**
  > 这位壮士且慢走！天光一落，村里鸡飞猪跳，昨夜西郊还见了半兽人的影子。
  > 你既是我比奇城的人，就替村子守一回门——杀几只乱窜的畜生立个威，再到西郊把那几个半兽人先锋撵走。
  > 事成之后，我让武场的铁教头传你两手保命的剑术。

- **AcceptText**
  > 天光异象后，比奇城周边鸡犬不宁，半兽人先锋已在西郊出没。[PLAYERNAME]受村长赵德旺之托，
  > 平息村中骚乱并清剿西郊半兽人，事成后前往武场向武教头·铁雄复命，习得入门剑术。

- **ProgressText**
  > 清理比奇城周边的鸡（0/5）、猪（0/3），并清剿西郊的半兽人（0/3）。

- **CompletedText**
  > 你清剿了袭扰村庄的野兽与半兽人，比奇城重归安宁。武教头·铁雄赞赏你的勇武，将传授你基本剑术。

- **武教头·铁雄 Say（交付页）**
  > 好小子，手脚利落！村长已经打过招呼了。我这一路剑术没别的，就是"稳、准、狠"三字——
  > 怪物扑上来的时候，害怕的人先死。拿去，先照着练，练熟了再来找我。

- **ArchiveText**
  > 天光初临之年，[PLAYERNAME]在比奇城完成村卫试炼，从武教头·铁雄处习得基本剑术，
  > 并获赠万事通留下的船长吊坠——那是他与"船"的第一缕牵绊。

**剧情分支**：无选择分支（线性）。交付页按钮树：`[领教剑术]` → 铁雄额外演示台词（无奖励）；
`[告辞]` → 任务关闭。

### 2.2 商路护卫（M3M_PW2_ESCORT）

**任务步骤**

| # | QuestTaskType | 参数 | 说明 |
|---|---------------|------|------|

| 3 | KillMonster | 虎蛇 ×6（毒蛇山谷） | 蛇群围攻商队 |
| 4 | KillMonster | 千年毒蛇 ×1（毒蛇山谷深处） | 蛇王劫镖（分支：硬闯才打） |

**奖励**

| 奖励 | 类型 | 说明 |
|------|------|------|

| 狩猎币 ×20 | GiveCurrency | 镖局酬谢 |
| 金创药(中) ×10 | Item | 路上伤药 |

**对话全文**

- **村长·赵德旺 Say（接取页）**
  > 商路断了。毒蛇山谷的蛇疯了似的拦路，往北的货走不出去，比奇城的粮价翻了三番。
  > 镖局的赵四海缺人手，你去搭把手——押这一趟镖，也算替村子挣条活路。

- **AcceptText**
  > 毒蛇山谷蛇患成灾，商路断绝。村长赵德旺举荐[PLAYERNAME]协助镖局赵四海押送商队出谷，
  > 清除拦路毒蛇，打通比奇城北上的商路。

- **ProgressText**
  > 抵达毒蛇山谷入口，护送商队：清除红蛇（0/8）、虎蛇（0/6），警惕蛇王千年毒蛇（0/1）。

- **CompletedText**
  > 商队平安出谷，毒蛇山谷商路重开。镖局师傅赵四海见你勇武可靠，将压箱底的攻杀剑术传了给你。

- **镖局师傅·赵四海 Say（交付页）**
  > 好汉子！这趟镖没有你，我老赵的招牌就砸在蛇窝里了。江湖人讲个"恩"字——这招攻杀剑术，
  > 是我年轻时在山贼堆里杀出来的，今日传你，望你用它护人，别用它伤人。

- **ArchiveText**
  > 商路断绝之年，[PLAYERNAME]护送商队穿过毒蛇山谷，击退蛇王千年毒蛇，习得攻杀剑术，
  > 比奇城北上商路自此重开。

**剧情分支（对话树）**：行至毒蛇山谷深处遇蛇王——

| 按钮 | 效果 |
|------|------|
| `[绕道而行]` | 少 500 金币镖银；不触发千年毒蛇击杀步骤（任务步骤 4 跳过） |
| `[硬闯过去]` | 触发 KillMonster 千年毒蛇 ×1；成功后镖银 +500、额外掉落「千年蛇胆」×1（任务道具） |

（实现：毒蛇山谷深处 NPC「蛇王劫道」对话页两个 Button → DestinationPage；硬闯页加 AddDataList
`M3_ESCORT_STRONG` 记录选择。）

  > 痛快！西郊的狼烟总算灭了。我替全城百姓谢你——这两样，你挑一样带走吧。往后比奇城的事，

- **ArchiveText**
  > 半兽人据点清剿一役，[PLAYERNAME]孤身拔寨、斩头目于阵前，比奇城西郊十年无兽患。

**剧情分支（掷骰子 Random 示范）**：清剿过半后，据点深处 NPC「半兽人头目」对话页：

| 页面 | 内容 |
|------|------|
| 劝降页 | 头目吼："人类！我沃玛大人麾下，岂会降你！" 按钮 `[举刀喝降]` |
| 判定 | NPCCheck.Random 50%（成功页 / 失败页） |
| 成功页 | 头目胆寒溃逃，半兽勇士剩余击杀数 -2（对话树 + 直接完成 2 只计数）；额外获得金币 +500、`M3_RAID_PERSUADE` 标记 |
| 失败页 | 头目狂怒反扑：追加 KillMonster 半兽勇士 ×2；无额外奖励 |

（实现：Random 判定 + SuccessPage/DestinationPage 分流；标记 `M3_RAID_PERSUADE` 供后续 NPC 彩蛋对话。）

  > 天然洞穴矿道塌方，老矿工陈永年被埋深处。矿场管事周老栓恳求[PLAYERNAME]下洞清理塌方、

  > 你说……天光那晚，你看见海上的大船了么？我年轻时……在船上当过水手……（忽然激动）
  > 船要开了！别让它开！它底下压着东西……压着东西啊！

- **ArchiveText**
  > 矿难之夜，[PLAYERNAME]从天然洞穴深处救出老矿工陈永年。陈永年胡话中提及"海上大船"，
