## 当前硬性原则

1. 原始客户端目录只读；所有分析结果写入本目录的 JSON/Markdown。
2. `primary-static` 只表示机器码/资源直接证据，不等于运行时确认。
3. 坐标表达式异常、超出父窗口或寄存器复用不清时，保留原始表达式并降级状态。
4. 预览器的候选层可以帮助检查视觉布局，但不能反过来证明原版坐标。
5. 每完成一个类别，都要同步更新本矩阵、`RESEARCH_LOG.md` 和 `layout.json`。
