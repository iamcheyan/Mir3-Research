## 1. 版本沿革

### 1.1 时间线（来自 ei2.cc 官网 / iamcheyan 复刻项目）

| 时间 | 事件 |
|------|------|
| 2001年 | 《热血传奇》（传奇2）风靡大江南北；同年韩国 **WEMADE** 开发续作 |
| 2001-2002 | 续作被玩家称为《传奇 ei2.0》，即 **EI** = **The Evil's Illusion**，中文名「**恶魔的幻影**」，次年在全球公测 |
| 2002年 | 盛大同 WEMADE 因纠纷中断代理；游戏改头换面，成为**光通代理的《传奇3》** |
| 2003年 | 光通《传奇3》开放公测，会员用户七位数、同时在线六位数 |
| 2012年 | 盛大《传奇3》1.45 版本基础上推出「西沙」新版本（保留元素、武器制炼、神舰等经典特色） |
| 2021年 | 民间复刻项目兴起：ei2.cc（DS-BLUE Engine）、iamcheyan 恶魔的幻影复刻（GeeM2→V8M2） |

### 1.2 关键认知

- **EI 2.0 恶魔的幻影 = 传奇3 的前身/初版**。韩国原版叫 EI（恶魔的幻影），盛大代理时叫《传奇2.0》，后因纠纷被光通接手改名《传奇3》。
- 传奇3 的经典内容（元素系统、武器制炼、神舰、三职业）全部继承自 EI 2.0。
- 「1.45 版本」被老玩家称为黄金时代——"神舰之后再无传奇"（玩家共识）。

## 2. 游戏开场背景故事

> 来源：游侠网《恶魔的幻影——传奇3》游戏评论（作者：游侠创作室 MICHANE，2003年）
> 原文：https://article.ali213.net/html/1746.html

### 2.1 开场剧情（游戏 CG/片头叙事）

> 拥有神奇力量的勇士们饱守酷热与寒冷的折磨，穿过神秘的**死亡峡谷**，经历**恶魔骷髅的巢穴**，终于来到神秘光线出现的地方。英雄们向前靠近物体。突然，随着一束刺眼的光线，人们都失去了知觉，昏倒在地上。
>
> 当他们再次苏醒过来，展现在眼前的是被**奇特的天光笼罩的广阔大地**。还看到了一个非常惊人的东西，那是一个**造型奇特的巨船**……
>
> 在这里，他们将经历一场**终身难忘的、最恐怖的噩梦**……

**叙事要素提取**：
- 起点：勇士穿越死亡峡谷（酷热与寒冷交替的试炼之路）
- 途经：恶魔骷髅的巢穴（亡灵/骷髅系怪物的叙事铺垫）
- 转折：神秘光线 → 昏迷 → 苏醒
- 新世界：奇特天光笼罩的广阔大陆（对应游戏内的"天光"美学，黑雾/天气系统）
- 核心意象：**造型奇特的巨船**（神舰/幽灵船的预言！）
- 基调：恐怖、噩梦、未知——玩家是被卷入灾难的"穿越者"

### 2.2 游戏主题（评论归纳）

- 传奇的故事"以无休止的血战为内容"，传奇3 延续传奇2 未讲完的情节，故事框架更紧凑，"各种战役高潮迭起"
- 传奇3 以**贴近武侠世界观**的方向走近玩家，秉持中国玩家"侠客主义"思想
- 新任务系统（职业任务/一般任务/每日任务）让游戏"跟读一本有故事有情节的武侠小说一样"
- 音乐随场景变化：绿洲的紧张、沃玛的锣鼓洞天、攻城的磅礴——场景都有情绪基调

## 3. 世界观设定：玛法大陆

> 来源：网络搜索摘要（传奇3背景故事相关文章）+ 本地术语文档交叉印证

### 3.1 大陆设定

- 传奇3 的故事发生在**玛法大陆**（与传奇2 共享的世界观基础）
- 玛法大陆的人类**继承了古代神人们传下的武功**，背后活跃着继承了**龙脉的武林宗师**
- 因此人类在抵抗**邪恶魔族侵略**和与各类怪物的战争中**处于不败之地**

### 3.2 核心冲突

```
古代神人(传下武功) ──→ 人类(玛法大陆) ──vs── 邪恶魔族 + 各类怪物
        ↑
    龙脉武林宗师(守护)
```

### 3.3 玩家身份

- 玩家是"自由流浪者 / 武林人士"一类角色——不是天生的救世主，而是在乱世中成长
- 这为"玩家从普通人开始，逐步卷入大战"的主线叙事提供了依据

## 4. 地图与区域背景

> 来源：17173 传奇3 地图专区 + ei2.cc 地图攻略 + 本地 mir2ei 数据

### 4.1 官方地图全集（17173 地图专区分类）

从 17173 地图专区提取的地图体系：

- **新手/城镇**：比奇省（新手村）、盟重省（土城）
- **练级区**：毒蛇山谷、天然洞穴、银杏废矿、矿区（僵尸洞）、灌木林、失乐园、赤月山谷
- **中级副本**：蚂蚁洞穴、虫峡谷、石阁阵、罪孽洞穴
- **高级神殿**：沃玛神殿、祖玛神殿、潘夜石窟、潘夜神殿
- **终极区域**：**真天宫和黑度宫**（对应本地数据的"真天黑度"）、神舰（幽灵船）、诺玛遗址
- **世界地图**：沙漠绿洲 → 西部沙漠（西沙版本扩展）

### 4.2 神舰（幽灵船）——核心叙事地点 ⭐

> 来源：ei2.cc 地图攻略 + 游侠网开场故事 + mir2ei 数据

- 神舰 = 游戏开场"造型奇特的巨船"的实体化
- 结构：共 3 层（1层甲板区、2层船舱区、3层船长室），入口在**失乐园海边**
- 开门时间：上午 11:50-11:51、晚上 19:30-20:30（每天定时开放）
- 怪物：海神将领/队长/卫士/弓箭手/法师、触角神魔、霸王守卫
- BOSS：**霸王幽灵**（9小时刷新）、**触角神魔**（6小时）
- 特殊物品：神舰通行证、船长的日志、深海珍珠（叙事性道具！）
- 掉落：黑皮靴子/手套/帽子、龙鳞战甲/战靴、祝福油；BOSS 掉破血狂杀、旋风流星刀、海洋之心、神舰船票
- 攻略要点：必须组队（2战+2道+1法）；死亡后失乐园复活

### 4.3 真天宫和黑度宫（终极区域）

- 对应本地数据的"真天黑度"地图（火焰狮子、石像狮子、武力神将、地牢女神、震天首将、**震天魔神**）
- BOSS：**震天魔神**（真天宫，30分钟刷新）——终极 BOSS

### 4.5 北方雪原背景故事（完整叙事示例）⭐

> 来源：ei2.cc 地图攻略（quest.html）——这是本地存档中**最完整的一段官方叙事**，可作为主线任务叙事模板

> 「征服者」国王扩张领土 → 军队北上遇暴风雪 → 发现冰中宝塔 → 二儿子+火影统治 → 火影独立 → 紫霞神女求援，大族长需要黎明女王和火影式英雄

- 怪物：雪狼、幽灵骑士、狼人、冰魄女神、冰魂斧兵/武士/弓箭手/武将、火影、冥血魔王
- BOSS：火影（8小时）、冥血魔王（12小时）
- 叙事道具：雪原通行证、征服者遗物、火影信物
- 玩法：需抗寒药水保暖装备；火影用冰系魔法对抗；暴风雪时找遮蔽

- 新玩法：强化技能（潜能系统）、阵法系统、每日任务

## 6. 职业体系
