## 2. 命名结构规则

### 2.1 物品名结构

```
[修饰词] + 主体词 + [部位/性别/等级后缀]

例：
Zuma Judgement Mace     → 祖玛裁决之锤
Advanced Destructive Surge → 高级破血狂杀（技能书）
Enchanted Iron Plate Armour (M) → 附魔铁板甲（男）
Elixir Of Destruction (V) → 毁灭灵药（五）
```

### 2.2 技能书命名

- 战士技能：剑术/刀法类（攻杀/刺杀/烈火/半月）
- 法师技能：术/咒/法类（火球术/雷电术/魔法盾）
- 道士技能：术/符/法类（施毒术/灵魂火符/召唤骷髅）
- 进阶技能：高级/强化/超强 前缀

### 2.3 怪物命名

```
[地域前缀] + 种族/形态 + [职能后缀]

例：
Oma Warrior → 祖玛卫士（地域+种族+职能）
Skeleton Lord → 骷髅王
Ghoul Champion → 食尸鬼冠军
```

### 2.4 地图命名

```
[地域] + [地形/建筑]

例：
Bichon Town → 比奇县
Zuma Temple → 祖玛神殿
Oma Cave → 沃玛神殿
Red Moon Valley → 赤月山谷
```

## 3. 避坑清单（易错点）

1. **Oma ≠ 欧玛**：Oma 是沃玛（光通经典译名），不是音译"欧玛"；
2. **Zuma ≠ 祖玛教**：Zuma 是"祖玛"（地名/种族），不是"祖玛教"；
3. **Guild ≠ 行会 vs 帮会**：统一用**行会**（光通版），不用"帮会/公会"；
4. **Companion ≠ 宠物 vs 伙伴**：UI 用**宠物**（CompanionDialog 标题），怪物召唤物用**召唤物**；
5. **Refine = 精炼**：不是"打磨/精锻"；
6. **Socket = 镶嵌**：不是"打孔/插槽"；
7. **Consignment = 寄售**：不是"委托/拍卖"；
8. **HP/MP/AC/DC 缩写保留**：属性缩写（HP/MP/AC/MAC/DC/SC/FP/CP）不翻译；
9. **人名保留音译**：NPC 人名（Henry/David/Isaac）保留英文或统一音译表；
10. **地名以地图表为准**：已译 280 张地图名是权威（map-chinese-name-table.md）。

## 4. 数据来源优先级

翻译数据层时按此优先级取词：

1. **item_catalog.json**（1078 物品，含中文名+描述）——最权威，先取；
2. **光通版经典译名**（本表 1.5/1.6/1.7 节）——冲突时以本表为准；
3. **map-chinese-name-table.md**（280 地图）——地名权威；
4. **quest-design 文档**（NPC/怪物零散译名）——补充；
5. 新词按本规则类推，并回填本表。
